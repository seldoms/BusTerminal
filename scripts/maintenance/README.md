# scripts/maintenance — 一次性维护脚本归档

这里存放曾经在 `backend/` 根目录下运行过的一次性脚本（修复、检查、迁移、探针类），
2026-10-25 仓库整洁时从 `backend/` 迁入（Issue #3 第一部分）。全仓 grep 确认它们
不被任何源码、测试、Dockerfile、compose 或文档引用，迁出后也不会被打进生产镜像
（`.dockerignore` 已排除 `scripts/`）。

注意：

- 这些脚本是**历史归档**，多数只针对当时的某次数据/环境问题写成，不要不加审查地
  对现网数据重复运行；其中涉及写库/改 schema 的脚本自带环境变量确认开关，
  运行前务必先备份并读懂脚本内容。
- 它们原本按「在 `backend/` 目录内运行」编写，若确需再用，请在 `backend/`
  目录上下文中运行（或把 `backend/` 加入 `PYTHONPATH`），并核对脚本内的相对路径。
- `job-probe.txt` 是当年留下的探针杂物文件（内容仅一行 `job-ok`），一并归档。
